# Руководство по локальному запуску (LCK.KZ)

Этот проект использует **Next.js** с **TypeScript** и **Tailwind CSS**.

## Предварительные требования

Перед началом убедитесь, что у вас установлены:
- **Node.js** (версия 18.17 или выше)
- **npm** (обычно устанавливается вместе с Node.js)

## Шаг 1. Установка зависимостей

Откройте терминал в папке проекта `lck-fresh` и выполните следующую команду для установки всех необходимых пакетов из `package.json`:

```bash
npm install
```

## Шаг 2. Запуск сервера для разработки

После того как зависимости установлены, запустите локальный сервер (Development Server):

```bash
npm run dev
```

Сервер запустится на порту `3000`.

## Шаг 3. Открытие проекта в браузере

Откройте браузер и перейдите по следующему адресу:
[**http://localhost:3000**](http://localhost:3000)

## Дополнительные команды

- Сборка проекта для продакшена (Production Build):
  ```bash
  npm run build
  ```
- Запуск собранного проекта:
  ```bash
  npm run start
  ```
- Проверка на ошибки линтинга (ESLint):
  ```bash
  npm run lint
  ```

Если при запуске возникают проблемы с зависимостями, вы можете удалить папку `node_modules` и файл `package-lock.json`, а затем заново выполнить `npm install`.
